# EmoCare-Sentiment-Analysis-of-Cancer-Survivors-and-Caregivers
EmoCare is a machine learning project focused on sentiment analysis of text from cancer survivors and caregivers. The goal of this project is to analyze textual data and identify underlying sentiment patterns that may provide insights into the emotional experiences shared by survivors and caregivers.

#### Objectives
Analyze sentiment-related patterns in the dataset.
Perform Exploratory Data Analysis (EDA).
Preprocess and prepare textual data for machine learning.
Apply the XGBoost machine learning algorithm.
Evaluate model performance on unseen test data.
Explore the potential of machine learning for healthcare-related sentiment analysis.

#### Machine Learning Model
**XGBoost**

The XGBoost (Extreme Gradient Boosting) algorithm was used as the primary classification model for sentiment prediction.

XGBoost was selected because of its strong performance on structured machine learning problems and its ability to capture complex relationships within the data.

Model Performance
Metric	Accuracy
Training Accuracy -	98%
Testing Accuracy -	70.8%

The difference between training and testing accuracy indicates that the model performs significantly better on the training data than on unseen data. This highlights the importance of evaluating model generalization and provides an opportunity for further improvement through feature engineering, hyperparameter tuning, and regularization.
